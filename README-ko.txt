MicKey — 마이크 단축키

Windows 10/11 64비트용 작은 마이크 제어 앱입니다.
ZIP을 푼 폴더의 MicKey.exe를 실행하세요. 별도 .NET 설치 없이 사용할 수 있습니다.

사용 방법
1. 로블록스에서 사용하는 마이크를 MicKey의 '입력 마이크'에서 선택합니다.
2. 말하기 방식을 고릅니다.
   • 누르는 동안 말하기: 단축키를 누르는 동안만 켜지고, 놓으면 음소거됩니다.
   • 한 번 눌러 전환: 단축키를 한 번 누를 때마다 켜짐/음소거가 바뀝니다.
3. 단축키 버튼을 클릭한 뒤 원하는 키를 누릅니다. 기본값은 V입니다.
   Ctrl / Alt / Shift 조합도 가능합니다. Esc로 변경을 취소합니다.
4. '마이크 제어 시작'을 누릅니다. 이 버튼은 항상 음소거 상태로 시작합니다.
   바로 켜려면 상태 카드의 '시작 · 마이크 켜기'를 누르세요.
5. 로블록스에서도 같은 입력 마이크를 선택하고, 게임 안 마이크는 켜 둡니다.

창을 최소화하거나 '트레이로 숨기기'를 누르면 뒤에서 계속 작동합니다.
작업 표시줄 알림 영역의 아이콘을 더블클릭하면 창이 다시 열립니다.
트레이 아이콘을 오른쪽 클릭하면 현재 상태와 '마이크 켜기 / 마이크 음소거' 메뉴가 표시됩니다.
'제어 중지' 또는 창의 X/트레이의 '종료'는 제어 시작 전 마이크 상태를 복원합니다.
앱을 다시 실행하면 제어는 꺼진 상태로 시작합니다.

앱과 트레이에서 마이크 전환 (1.3)
• 상태 카드의 '마이크 켜기 / 마이크 음소거' 버튼으로 직접 조작하세요.
  트레이에서도 같은 메뉴를 사용할 수 있습니다. 아직 제어 중이 아니면 제어를 시작하며 바로 켭니다.
• 누르는 동안 말하기 모드에서 직접 켜면 키를 누르지 않아도 켜진 상태를 유지합니다.
  버튼으로 다시 끄거나, 단축키를 새로 눌렀다 놓으면 일반 PTT로 돌아갑니다.
• 수동 켜짐 상태를 화면과 오버레이에 표시합니다. 효과음도 기존 설정대로 재생됩니다.
• 입력 보호는 단축키에 적용됩니다. 직접 켠 상태는 입력 중에도 유지됩니다.
  설정창 열기·단축키 변경·모드 변경·잠금·절전 때는 음소거합니다.

효과음 (1.1)
메인 화면 또는 트레이의 '설정 · 입력 보호 · 효과음 · 오버레이'에서 조절합니다.
• 켤 때/누를 때와 끌 때/놓을 때 소리를 각각 고를 수 있습니다.
  부드러운 알림음, 디지털 비프, 짧은 클릭, 소리 없음 중 선택하세요.
• 효과음 볼륨(0~100%)은 앱의 알림 소리만 바꿉니다. Windows 전체 볼륨은 그대로입니다.
• '이어폰 / 출력 장치'에서 실제 이어폰 출력을 고르고 '미리 듣기'로 확인하세요.
  Windows 기본 출력도 선택 가능합니다. 특정 장치를 골랐다면 연결이 끊겨도 다른 출력으로 바꾸지 않습니다.
• 누르는 동안 말하기와 한 번 눌러 전환 모두 마이크가 실제 바뀐 뒤 효과음을 재생합니다.
  빠르게 누르면 마지막 상태의 효과음이 우선 재생됩니다. 미리 듣기는 마이크를 켜지 않습니다.

오버레이 (1.1)
• 설정의 '오버레이' 탭에서 켜고 끄며 크기(75~175%), 불투명도(35~100%)를 조절합니다.
• '위치 미리보기 · 이동'을 누르고 작은 상태창을 드래그한 뒤 '위치 이동 완료'를 누르세요.
  위치는 저장됩니다. '위치 초기화'는 주 모니터 오른쪽 위로 되돌립니다.
• 평소에는 클릭을 통과시켜 게임 조작을 방해하지 않습니다. 앱을 트레이로 숨겨도 유지됩니다.
• 기본적으로 마이크 제어 중에만 표시합니다. '마이크 제어가 꺼져 있어도 표시'를 켤 수도 있습니다.
• 일반 데스크톱 오버레이라 독점 전체 화면 게임 위에는 안 보일 수 있습니다. 창 모드를 사용하세요.
제어 중 설정창을 열면 마이크는 음소거되며, 설정을 닫고 단축키를 새로 눌러 다시 말할 수 있습니다.

입력 보호와 설정 저장 (1.2)
설정의 '입력 · 저장' 탭에서 조절합니다.
• 입력창 자동 감지는 커서가 보이는지가 아니라 Windows 접근성의 입력 포커스로 판단합니다.
  디스코드·브라우저 등에서 입력창으로 인식되는 동안 마이크 단축키를 잠급니다.
• 게임처럼 입력창 감지가 어려우면 앱 실행파일과 채팅 시작 키를 등록하세요.
  예: 해당 게임 실행파일 + T. 기본 Roblox 채팅 규칙은 /이며 변경할 수 있습니다.
  그 키를 누른 순간부터 보호하고 Enter/Esc로 해제합니다. Shift+Enter는 유지합니다.
  다른 창으로 이동해도 해당 게임 창의 채팅 보호는 기억합니다. 최대 32개 앱을 등록할 수 있습니다.
• 수동 잠금/해제 기본 키는 Ctrl+Alt+F10이며 변경 가능합니다.
  메인 화면/트레이의 '입력 보호 해제'도 사용할 수 있습니다.
  실제 입력창에 포커스가 남아 있으면 자동 보호는 계속됩니다.
• 보호 중 토글 모드는 현재 켜짐/꺼짐을 유지하고, 누르는 동안 말하기는 음소거됩니다.
  단, 앱·트레이 버튼으로 직접 켠 상태는 유지됩니다.
  보호 해제 후에는 단축키를 놓았다가 다시 눌러 주세요. 오버레이에도 입력 보호를 표시합니다.
• 커스텀 게임 UI, 마우스로 연 채팅, 누른 뒤 입력창이 생기는 앱은 자동 감지가 완벽하지 않습니다.
  앱별 규칙이나 수동 잠금을 함께 사용하세요. Enter가 한글 조합 확정이나 줄바꿈만 하는 게임에서는
  규칙의 보호가 먼저 풀릴 수 있습니다. 채팅 키와 마이크 키가 같으면 채팅 보호를 우선합니다.
• 모든 설정은 자동 저장됩니다. '설정 저장'과 JSON 파일 내보내기/불러오기도 가능합니다.
  불러오면 제어가 중지됩니다. 다른 PC에서는 마이크·효과음 출력을 다시 선택한 뒤 시작하세요.
  현재 마이크 켜짐 상태는 저장하지 않습니다. 입력한 문장이나 메시지도 읽거나 저장하지 않습니다.

알아두면 좋은 점
• 이 앱은 마이크 장치 자체를 제어하므로 디스코드 등 같은 마이크를 쓰는 앱에도 적용됩니다.
• 다른 앱으로 전달되는 단축키 입력을 막지 않습니다. 같은 키에 연결된 게임 동작도 실행될 수 있습니다.
• 선택한 마이크만 제어합니다. Windows 기본 마이크가 바뀌어도 자동 전환하지 않습니다.
• 장치를 다시 연결했거나 오류로 제어가 중지되면 '새로고침' 후 마이크를 선택하고 다시 시작하세요.
• 잠금·절전 및 복귀 시 음소거합니다. 이미 누르고 있던 단축키는 놓았다가 다시 누르세요.
• 강제 종료나 충돌 때는 음소거/이전 상태 복원을 보장할 수 없습니다.
  일부 드라이버나 독점 모드 앱은 Windows 음소거 설정을 따르지 않을 수 있습니다.

설정은 %LOCALAPPDATA%\MicKey\settings.json에 자동 저장됩니다.
오류가 있으면 같은 폴더의 errors.log에 기록됩니다.
음성을 녹음하거나 전송하지 않으며, 네트워크 통신·사용 기록 수집 기능이 없습니다.

소스에서 빌드
.NET 8 SDK가 설치된 환경에서 PowerShell로 .\build.ps1을 실행하세요.
입력/상태 전환 테스트를 통과한 뒤 dist\MicKey.exe를 생성합니다.
