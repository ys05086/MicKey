# MicKey

키보드로 Windows 마이크의 음소거를 제어하는 작은 데스크톱 앱입니다. 누르는 동안 말하기(PTT), 한 번 눌러 전환, 효과음, 상태 오버레이를 지원합니다.

**[Windows용 실행 ZIP 다운로드](https://github.com/ys05086/MicKey/releases/latest)**

Windows 10/11 **64비트(x64)**용입니다. ZIP을 풀고 `MicKey.exe`를 실행하세요. 배포본에는 .NET 런타임이 포함되어 있어 별도 .NET 설치가 필요하지 않습니다.

## 사용 방법

1. 게임이나 음성채팅 앱에서 사용하는 입력 마이크를 선택합니다.
2. 말하기 방식을 선택합니다.
   - **누르는 동안 말하기:** 단축키를 누르는 동안만 음소거를 해제하고 놓으면 다시 음소거합니다.
   - **한 번 눌러 전환:** 단축키를 누를 때마다 음소거와 켜짐을 전환합니다.
3. 단축키 버튼을 클릭하고 원하는 키를 누릅니다. 기본값은 **V**이며 Ctrl/Alt/Shift 조합도 지원합니다.
4. **마이크 제어 시작**을 누릅니다. 시작할 때는 항상 음소거 상태입니다.
5. 로블록스에서 사용한다면 같은 입력 마이크를 선택하고 게임 안 마이크는 켜 둡니다.

단축키와 마이크 선택은 자동 저장됩니다. 앱은 다시 실행할 때 제어가 꺼진 상태로 시작합니다.

## 효과음과 오버레이

메인 화면 또는 트레이의 **효과음 · 오버레이 설정**을 엽니다.

- 마이크 켜짐/꺼짐에 서로 다른 알림음을 재생합니다. 부드러운 알림음, 디지털 비프, 짧은 클릭, 소리 없음 중 각각 고를 수 있습니다.
- 효과음 볼륨과 출력 장치를 선택하고 미리 들어볼 수 있습니다. 효과음 볼륨은 Windows 전체 볼륨을 변경하지 않습니다.
- 오버레이의 표시 여부, 크기, 불투명도를 조절합니다. **위치 미리보기 · 이동**에서 표시창을 드래그해 위치를 저장합니다.
- 평소 오버레이는 클릭을 통과시킵니다. 제어 중 설정창을 열면 마이크는 음소거됩니다.

창을 최소화하면 트레이에서 계속 작동합니다. 트레이 아이콘을 더블클릭하면 창을 다시 엽니다. 제어 중지 또는 정상 종료 시에는 제어 시작 전 마이크 상태로 복원합니다.

## 동작 원리와 범위

Windows Core Audio의 `IAudioEndpointVolume.SetMute`로 선택한 마이크 장치의 음소거 상태를 변경합니다. 마이크 볼륨 수치를 줄이거나 게임 코드를 수정하는 방식이 아닙니다.

- **같은 마이크를 쓰는 모든 앱에 적용됩니다.** 로블록스와 디스코드가 같은 마이크를 사용한다면 둘 다 영향을 받습니다.
- 음성을 녹음하거나 전송하지 않으며 앱에 네트워크 통신 기능이 없습니다.
- 키보드 입력을 다른 앱으로 전달하는 것을 막지 않습니다. 같은 키의 게임 동작도 실행될 수 있습니다.
- 선택한 입력 장치를 고정해서 사용합니다. Windows 기본 마이크가 바뀌어도 자동 전환하지 않습니다.
- 강제 종료, 장치 오류 또는 일부 드라이버/독점 모드에서는 음소거와 상태 복원을 보장할 수 없습니다.
- 일반 데스크톱 오버레이라 독점 전체 화면 게임 위에는 표시되지 않을 수 있습니다. 이 경우 창 모드를 사용하세요.

MicKey는 Roblox의 공식 앱이나 제휴 제품이 아닙니다.

## 설정과 진단

개인 설정은 `%LOCALAPPDATA%\MicKey\settings.json`, 오류 기록은 같은 폴더의 `errors.log`에 저장됩니다. 이 파일들은 소스와 실행 ZIP에 포함되지 않습니다.

장치를 다시 연결했다면 제어를 중지하고 **새로고침**을 누른 뒤 마이크를 다시 선택하세요. 효과음은 명시적으로 선택한 출력 장치가 사라지면 다른 장치로 자동 전환하지 않습니다.

## 소스에서 빌드

Windows와 .NET 8 SDK가 필요합니다.

```powershell
git clone https://github.com/ys05086/MicKey.git
cd MicKey
.\build.ps1
```

입력 상태, 오버레이 배치, 효과음 검사를 실행한 뒤 `dist\MicKey.exe`에 독립 실행형 x64 빌드를 만듭니다.

추가로 실제 창 동작을 검사하려면 다음 명령을 실행합니다. 검사 중 잠시 테스트 창이 표시됩니다.

```powershell
dotnet run --project tests/OverlayTests/OverlayTests.csproj -c Release -- --native
```

효과음 테스트는 기본 실행에서는 소리를 재생하지 않습니다. `--list`로 출력 장치 ID를 확인하고 `--play <deviceId>`를 지정하면 해당 장치에서 짧은 실제 재생 검사를 수행합니다.

배포 ZIP의 `licenses/`에는 포함된 .NET 런타임의 라이선스와 제3자 고지문이 들어 있습니다.
